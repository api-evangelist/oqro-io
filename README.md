OQRO is a free public data service that aggregates US company, fund, congressional, and government disclosures, turning each filing into a plain‑line summary with a link to the official source. It provides insider trades, fund moves, politician trades, federal contracts, lobbying, M&A, and other filings in an accessible, searchable format for the public.

**Areas:** Insider trades · Politician trades · Fund moves · Federal contracts · Mergers and acquisitions · Financial data API · US public filings

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for OQRO: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
